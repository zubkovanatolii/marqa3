# MARQA Level 1: Link Analyzer

## Deployment on Vercel (ZIP)
1. Create new project on Vercel → Import project → Create from ZIP.
2. Upload this zip.
3. Add Environment Variable:
   GOOGLE_PAGESPEED_API_KEY=your_key_here
4. Deploy.

## Deployment on Vercel (Git)
1. git init && git add . && git commit -m "Level 1"
2. git branch -M main
3. git remote add origin https://github.com/your/repo.git
4. git push -u origin main
5. In Vercel, Import Git Repository → choose this repo.
6. Add ENV var and Deploy.

## Usage
1. Open https://<your-domain>.vercel.app
2. Enter URL → Analyze
3. View table of link statuses.
